¿Qué es el módulo datetime de Python y cuáles son sus utilidades principales?;Es un módulo estándar de Python que proporciona clases y métodos para trabajar con fechas y horas.<ul><li>Permite instanciar fechas y horas.</li><li>Permite realizar operaciones aritméticas entre fechas.</li><li>Permite formatear e interpretar cadenas de texto con fechas.</li><li>Permite gestionar zonas horarias.</li></ul>
¿Cómo se importa y crea un objeto de la clase date en Python?;Se importa desde el módulo <code>datetime</code> y se instancia pasando año, mes y día.<br><pre><code class="language-python">from datetime import date\nfecha = date(year=2025, month=8, day=25)</code></pre>
¿Cuáles son los atributos principales de un objeto date y qué tipo de dato devuelven?;Devuelven valores enteros (<code>int</code>) correspondientes a cada componente:<ul><li><code>.year</code>: Año de la fecha.</li><li><code>.month</code>: Mes de la fecha.</li><li><code>.day</code>: Día de la fecha.</li></ul><br><pre><code class="language-python">fecha = date(2025, 1, 1)\nprint(fecha.year)  # 2025\nprint(type(fecha.year))  # &lt;class 'int'&gt;</code></pre>
¿Cómo se obtiene la fecha actual del sistema usando la clase date?;Se utiliza el método de clase <code>date.today()</code>.<br><pre><code class="language-python">from datetime import date\nfecha_actual = date.today()</code></pre>
¿Cómo funciona el método weekday() en la clase date y cuál es su rango de valores?;Devuelve un entero que representa el día de la semana, comenzando en 0.<ul><li><b>0:</b> Lunes</li><li><b>1:</b> Martes</li><li><b>2:</b> Miércoles</li><li><b>3:</b> Jueves</li><li><b>4:</b> Viernes</li><li><b>5:</b> Sábado</li><li><b>6:</b> Domingo</li></ul><br><pre><code class="language-python">fecha = date(2026, 10, 10)\nprint(fecha.weekday())  # Retorna 5 (Sábado)</code></pre>
¿Cómo se crea un objeto de la clase datetime en Python?;Se instancia pasando parámetros de fecha y hora obligatorios u opcionales.<br><pre><code class="language-python">from datetime import datetime\ndt = datetime(year=2025, month=8, day=25, hour=14, minute=23, second=56, microsecond=0)</code></pre>
¿Cuáles son los atributos disponibles en un objeto datetime?;Permite acceder individualmente a todos sus componentes:<ul><li><code>.year</code>: Año</li><li><code>.month</code>: Mes</li><li><code>.day</code>: Día</li><li><code>.hour</code>: Hora</li><li><code>.minute</code>: Minutos</li><li><code>.second</code>: Segundos</li><li><code>.microsecond</code>: Microsegundos</li></ul>
¿Cómo se extrae un objeto date a partir de una instancia de datetime?;Se utiliza el método de instancia <code>.date()</code>.<br><pre><code class="language-python">dt = datetime(2025, 8, 25, 14, 23, 56)\nfecha_solo = dt.date()  # Retorna datetime.date(2025, 8, 25)</code></pre>
¿Cómo se extrae un objeto time a partir de una instancia de datetime?;Se utiliza el método de instancia <code>.time()</code>.<br><pre><code class="language-python">dt = datetime(2025, 8, 25, 14, 23, 56)\nhora_solo = dt.time()  # Retorna datetime.time(14, 23, 56)</code></pre>
¿Cuál es la diferencia entre datetime.today() y datetime.now()?;Ambos devuelven la fecha y hora actual local, pero tienen diferencias de uso:<ul><li><code>datetime.today()</code>: Método heredado que retorna el datetime actual local sin zona horaria.</li><li><code>datetime.now()</code>: Permite recibir opcionalmente un parámetro de zona horaria (<code>tz</code>) para obtener la hora localizada.</li></ul><br><pre><code class="language-python">print(datetime.now())\nprint(datetime.today())</code></pre>
¿Cómo se consultan las zonas horarias disponibles mediante la librería pytz?;Se accede al atributo <code>pytz.all_timezones</code>, el cual contiene una lista de cadenas con todas las zonas horarias registradas.<br><pre><code class="language-python">import pytz\nprint(pytz.all_timezones)</code></pre>
¿Cómo se filtra una zona horaria específica dentro de pytz.all_timezones?;Se puede utilizar la función <code>filter()</code> junto a una función <code>lambda</code>.<br><pre><code class="language-python">import pytz\nresultado = list(filter(lambda x: "Bogota" in x, pytz.all_timezones))\n# ['America/Bogota']</code></pre>
¿Cómo se aplica una zona horaria a un objeto datetime actual?;Se crea el objeto timezone con <code>pytz.timezone()</code> y se aplica mediante <code>.astimezone()</code> sobre <code>datetime.now()</code>.<br><pre><code class="language-python">import pytz\nfrom datetime import datetime\ntz = pytz.timezone('America/Bogota')\nprint(datetime.now().astimezone(tz))</code></pre>
¿Qué tipo de objeto produce la resta de dos fechas (date o datetime)?;Produce un objeto de la clase <code>datetime.timedelta</code> que representa la diferencia de tiempo entre ambas fechas.<br><pre><code class="language-python">d1 = date(2025, 1, 1)\nd2 = date(2025, 3, 15)\ndiferencia = d2 - d1  # Objeto timedelta</code></pre>
¿Cuáles son los atributos principales para extraer información de un objeto timedelta?;Los atributos principales de lectura directa son:<ul><li><code>.days</code>: Número de días enteros de diferencia.</li><li><code>.seconds</code>: Segundos restantes de la diferencia (excluyendo días enteros).</li></ul><br><pre><code class="language-python">diferencia = fecha_final - fecha_inicial\nprint(diferencia.days)\nprint(diferencia.seconds)</code></pre>
¿Existe el atributo .hours en un objeto timedelta?;<b>No.</b> Acceder a <code>diferencia.hours</code> genera un error de atributo (<code>AttributeError</code>). Para obtener horas se deben calcular a partir de los segundos (<code>seconds / 3600</code>).
¿Cómo se suma o resta tiempo a una fecha usando timedelta?;Se crea una instancia de <code>timedelta</code> especificando los argumentos deseados (<code>days</code>, <code>hours</code>, <code>minutes</code>, etc.) y se suma o resta a la fecha.<br><pre><code class="language-python">from datetime import datetime, timedelta\n# Sumar 1 día a la fecha actual\nfuturo = datetime.now() + timedelta(days=1)\n# Sumar 4 días y 3 horas a un datetime\nfecha_calc = datetime(2025, 6, 13, 11, 34, 50) + timedelta(days=4, hours=3)</code></pre>
¿Para qué sirve el método datetime.strptime() y cuál es su sintaxis?;Sirve para convertir una cadena de texto (<code>str</code>) en un objeto <code>datetime</code> según un formato especificado.<br><pre><code class="language-python">from datetime import datetime\ncadena = "31/01/25 23:59:28"\nobj_dt = datetime.strptime(cadena, "%d/%m/%y %H:%M:%S")</code></pre>
¿Qué ocurre si la cadena de texto no coincide exactamente con el formato dado en strptime()?;Python lanza una excepción de tipo <code>ValueError</code> indicando que los datos de tiempo no coinciden con el formato especificado.<br><pre><code class="language-python"># Genera ValueError porque el separador '-' no coincide con '/'\ndatetime.strptime("31-01-25 23:59:28", "%d/%m/%y %H:%M:%S")</code></pre>
¿Para qué sirve el método strftime() y cuál es su sintaxis?;Sirve para convertir un objeto <code>datetime</code> o <code>date</code> a una cadena de texto (<code>str</code>) formateada según modificadores.<br><pre><code class="language-python">fecha = datetime(2025, 8, 25, 16, 36, 15)\ntexto = fecha.strftime("%A %d %B %Y. %I:%M%p")</code></pre>
¿Qué representan los principales modificadores de formato en strftime() y strptime()?;<ul><li><code>%d</code>: Día del mes con dos dígitos (01 a 31).</li><li><code>%m</code>: Mes con dos dígitos (01 a 12).</li><li><code>%y</code>: Año en 2 dígitos (ej. 25).</li><li><code>%Y</code>: Año en 4 dígitos (ej. 2025).</li><li><code>%H</code>: Hora en formato 24 horas (00 a 23).</li><li><code>%I</code>: Hora en formato 12 horas (01 a 12).</li><li><code>%M</code>: Minutos (00 a 59).</li><li><code>%S</code>: Segundos (00 a 59).</li><li><code>%A</code>: Nombre completo del día de la semana.</li><li><code>%B</code>: Nombre completo del mes.</li><li><code>%p</code>: Indicador AM o PM.</li></ul>
¿Cómo influye el módulo locale en el formateo de fechas con strftime()?;Permite cambiar el idioma de los nombres de días y meses impresos por modificadores como <code>%A</code> o <code>%B</code>.<br><pre><code class="language-python">import locale\nlocale.setlocale(locale.LC_ALL, "es_ES.UTF-8")\n# Imprime los nombres en español (ejemplo: "lunes 25 agosto")</code></pre>
