¿Qué es una list comprehension en Python?;Es una forma concisa y elegante de crear una lista aplicando una expresión a cada elemento de un iterable en una sola línea de código.[cite: 1]
¿Cuál es la sintaxis básica de una list comprehension?;[nueva_expresion for elemento in iterable][cite: 1]
¿Cuál es la sintaxis de una list comprehension con un condicional?;[nueva_expresion for elemento in iterable if condicion][cite: 1]
¿Cómo se crea una lista del 1 al 10 usando list comprehension?;lista = [i for i in range(1, 11)][cite: 1]
¿Cómo se crea una lista con los cuadrados de otra lista 'numeros' usando list comprehension?;cuadrados = [x**2 for x in numeros][cite: 1]
¿Cómo se filtran solo los números pares de una lista 'numeros' usando list comprehension?;pares = [x for x in numeros if x%2 == 0][cite: 1]
¿Para qué se utiliza el método join() en Python?;Para unir una secuencia de cadenas de texto en una sola cadena usando un delimitador específico.[cite: 1]
¿Cuál es la sintaxis del método join()?;delimitador.join(iterable)[cite: 1]
¿Cómo se unen los elementos de la lista ['a', 'b'] separados por un guion usando join()?;"-".join(['a', 'b'])[cite: 1]
¿Cómo se aplica el método title() a cada string de la lista 'nombres' dentro de una list comprehension?;[nombre.title() for nombre in nombres][cite: 1]
¿Cuándo es ideal utilizar un bucle for?;Cuando se conoce el número de iteraciones o se tiene una secuencia/iterable para procesar.[cite: 2]
¿Cuándo es ideal utilizar un bucle while?;Cuando el número de iteraciones no es conocido y depende de una condición dinámica o evento externo.[cite: 2]
¿Qué estructura de repetición usar para iterar sobre una secuencia como listas o tuplas?;Se debe utilizar el bucle for.[cite: 2]
¿Qué estructura de repetición usar si la condición de parada depende de una entrada externa o evento dinámico?;Se debe utilizar el bucle while.[cite: 2]
¿Cuál estructura de control ofrece un control más detallado sobre la condición de salida impredecible?;El bucle while.[cite: 2]
¿Qué hace la sentencia break dentro de un bucle?;Interrumpe y finaliza la ejecución del ciclo de manera inmediata.[cite: 3]
¿Qué hace la sentencia continue dentro de un bucle?;Omite el resto del código del ciclo actual y pasa a la siguiente iteración.[cite: 3]
¿Cómo se detiene un bucle while cuando una variable 'contador' alcanza el valor 13?;if contador == 13: break[cite: 3]
¿Cómo se salta la iteración actual en un bucle while cuando 'contador' es igual a 13?;if contador == 13: contador += 1; continue[cite: 3]
¿Cómo se interrumpe un bucle for al encontrar el elemento 'Freezer' en la lista 'personajes'?;if personaje == "Freezer": break[cite: 3]
¿Cómo se omite procesar el elemento 'Freezer' en un bucle for sin salir del ciclo?;if personaje == "Freezer": continue[cite: 3]
